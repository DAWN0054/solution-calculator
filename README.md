# 溶液配制计算器 v2.1 · Solution Calculator

一个轻量、纯前端的溶液配制参数计算工具。输入分子量 M<sub>0</sub>，再给出质量 / 体积 / 浓度等参数中的若干项，即可自动计算缺失的那一项。支持固体溶质、纯液体溶质、溶液溶质（母液稀释）三种模式。

单个 HTML 文件，零依赖、无需安装，双击即可在本地使用，也适合部署到 GitHub Pages 等任意静态托管，在电脑、手机、平板上通用。

在线网址，可以直接使用：https://dawn0054.github.io/solution-calculator/
目前已经更新至v2.1，修复了一些已知的问题，对于溶液类溶质的配制更友好。

## 功能特点

- 三种溶质模式一键切换：固体溶质 / 纯液体溶质 / 溶液溶质
- 留空任意一项自动计算；留空两项及以上会提示补充参数
- 质量、体积、浓度、密度、分数等参数均可自由切换单位并自动换算
- 纯度 p 自动校验 0–100%
- 体积按加和近似处理，并对浓度方程做一致性校验，不一致时给出警告
- 中间量（物质的量 n、溶质质量）可折叠展示
- 响应式布局，适配电脑 / 手机 / 平板

## 快速上手

1. 用浏览器打开 `index.html`（或访问在线网址）。
2. 在顶部选择溶质形态。
3. 填写已知参数，**把想要计算的那一项留空**。
4. 点击「开始计算」，结果会自动填入空栏；点「中间量」可查看 n 与溶质质量。

## 三种模式与公式

### 1. 固体溶质

```
c = m · p / (M0 · V)
```

参数：分子量 M<sub>0</sub>（必填）、溶质质量 m、纯度 p、物质的量浓度 c、溶剂体积 V。

### 2. 纯液体溶质

```
m  = ρl · Vl · p
c  = m / (M0 · Vt)
Vs = Vt − Vl
```

参数：分子量 M<sub>0</sub>、纯液体密度 ρ<sub>l</sub>、纯度 p、纯液体体积 V<sub>l</sub>、总体积 V<sub>t</sub>、加入溶剂体积 V<sub>s</sub>、目标浓度 c。

### 3. 溶液溶质（母液稀释）

页面内可选三种浓度口径：

```
通用：c = m溶质 / (M0 · Vt)  ，  Vs = Vt − V0
```

| 口径 | 含义 | 溶质质量 | 额外参数 |
| --- | --- | --- | --- |
| w-w | 质量-质量分数 | m溶质 = w · ρ0 · V0 | 母液密度 ρ<sub>0</sub> |
| w-V | 质量-体积浓度 | m溶质 = (w/V) · V0 | 无 |
| V-V | 体积-体积分数 | m溶质 = ρl · φ · V0 · p | 纯溶质密度 ρ<sub>l</sub>、纯度 p |

参数：分子量 M<sub>0</sub>、母液体积 V<sub>0</sub>、总体积 V<sub>t</sub>、加入溶剂体积 V<sub>s</sub>、目标浓度 c，以及所选口径对应的 w / ρ<sub>0</sub>、w/V、φ / ρ<sub>l</sub> / p。

## 单位与换算

| 物理量 | 可选单位 |
| --- | --- |
| 质量 m | kg / g / mg / ng |
| 体积 V、V<sub>l</sub>、V<sub>t</sub>、V<sub>s</sub>、V<sub>0</sub> | L / mL / μL / nL |
| 浓度 c | M / mM / μM / nM / pM |
| 密度 ρ | g/mL（= g/cm³）/ g/L / kg/L / kg/m³ |
| 分数 w、φ | % / 小数（0–1） |
| 纯度 p | %（0–100） |
| 质量-体积浓度 w/V | g/100mL / g/L / g/mL |

切换单位时，已填写的数值会自动换算。

## 计算规则与注意事项

- **留空规则**：只留空一项则计算该项；留空两项及以上会提示补充；全部填写会提示“无需计算”。
- **体积加和近似**：V<sub>t</sub> = V<sub>l</sub> + V<sub>s</sub>（或 V<sub>t</sub> = V<sub>0</sub> + V<sub>s</sub>），忽略混合体积收缩；页面上有加粗提醒。
- **多解优先级**：当 V<sub>t</sub>、V<sub>l</sub>、V<sub>0</sub> 留空时，优先按体积加和求解，并对浓度方程做一致性校验；不一致时显示 ⚠ 警告。
- **纯度范围**：p 取值 0–100%，超出会提示错误。
- **精度**：结果按约 10 位有效数字显示。
- **隐私**：全部计算在本地浏览器完成，不上传、不保存任何数据。

## 本地使用与部署

- **本地使用**：双击 `index.html` 即可。
- **在线部署**：把 `index.html` 上传到任意静态托管即可，无需服务器或后端。以 GitHub Pages 为例：
  1. 新建（或进入已有）仓库，上传 `index.html` 到仓库根目录；
  2. Settings → Pages → Source 选 `main` + `/ (root)` → Save；
  3. 稍候访问 `https://你的用户名.github.io/仓库名/`。

### 更新版本（地址保持不变）

在线网址由“仓库名 + Pages 设置”决定，与文件内容无关。因此**在同一个仓库中覆盖 `index.html` 即可更新内容、网址不变**：

1. 进入原仓库 → Add file → Upload files；
2. 拖入新的 `index.html` 覆盖旧文件 → Commit changes；
3. 约 1 分钟后自动生效，原网址内容即替换为新版本（刷新时按 Ctrl+F5 强制刷新）。

### 多版本共存（原网址指向 v2.0，同时保留 v1.0）

若希望原网址指向 v2.0，同时在仓库中保留旧版供后来人选择：

1. 先把旧版 v1.0 的 `index.html` 放入 `v1/` 子目录（先建 `v1` 文件夹再上传，再覆盖根目录，否则旧版会丢失）；
2. 再用 v2.0 的 `index.html` 覆盖仓库根目录的 `index.html`；
3. 结果：`https://用户名.github.io/仓库名/` 为 v2.0，`https://用户名.github.io/仓库名/v1/` 为 v1.0。
