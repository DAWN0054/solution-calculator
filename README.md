# 溶液配制计算器 · Solution Prep Calculator

一个轻量的在线小工具：已知分子量 M0，给出溶质质量 m、物质的量浓度 c、溶剂体积 V 中任意两项，自动计算第三项。

## 功能

- 自动计算物质的量浓度 c、溶质质量 m、溶剂体积 V 三者中的缺项
- 分子量 M0 为必填项，单位为 g/mol
- 忽略溶质体积，认为溶剂体积 ≈ 溶液体积，即 `c = m / (M0 · V)`
- 质量单位：kg / g / mg / ng
- 体积单位：L / mL / μL / nL
- 浓度单位：M / mM / μM / nM / pM
- 单位可切换，切换时自动换算
- 响应式界面，电脑 / 手机 / 平板均可使用

## 使用

直接用浏览器打开 `index.html` 即可；部署到 GitHub Pages 后，用生成的网址访问。

## 隐私

全部计算在浏览器本地完成，不上传、不保存任何数据。

## 技术

单个 HTML 文件，原生 HTML + CSS + JavaScript，无任何外部依赖。
